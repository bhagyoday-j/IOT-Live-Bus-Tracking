# SMARTTRANSIT Frontend

A production-ready React 19 + Vite frontend for the SMARTTRANSIT intelligent public transportation management system.

## Features

- Passenger portal with route planning, live tracking, notifications, and profile management
- Depot manager dashboard with live fleet analytics and operations insights
- Admin portal with management screens for buses, routes, drivers, stops, depots, and users
- Role-based authentication and protected navigation
- Dark mode persistence
- Real API integration through the documented backend contracts

## Scripts

- npm install
- npm run dev
- npm run build

## Environment

Set the backend base URL in .env:

VITE_API_URL=http://localhost:5000/api
